# Custom data

This directory contains persistent, human-maintained local data.

- `fake-ip-filter.list`: local Fake-IP exclusions merged with the upstream OpenClash filter.
- `hosts.yaml`: local static hosts merged with fetched host sources; local entries win.

Generated data must not be maintained here:

- `META.yaml` Fake-IP and hosts sections are regenerated by Update Checker.
- Shadowrocket artifacts are generated from META/modules.

Routing policy remains in `Clash/ClashDirect.yaml`, `Clash/ClashProxy.yaml`, and `Clash/ClashReject.yaml`.
